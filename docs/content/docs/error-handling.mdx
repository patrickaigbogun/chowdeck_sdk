## Overview

When integrating with live APIs, things will inevitably go wrong at some point—whether it's an invalid request payload, an unauthenticated call, a business-rule violation, or a temporary network drop.

The goal of error handling in the Chowdeck SDK is simplicity: **we allow you to handle the error directly within your own code without wrapping failures in obscure or unnecessary abstractions.**

If an error comes from the Chowdeck API server or the underlying network runtime, the SDK exposes the exact context (status codes, response bodies, and request parameters) so you can immediately see what failed and fix it.

---

## The Error Hierarchy

All errors thrown by the SDK extend from the root `ChowdeckError` class.

```
       ChowdeckError (Base Error Class)
             │
             ├── ChowdeckAPIError (HTTP 4xx/5xx API Responses)
             └── ChowdeckConnectionError (Network/Fetch Failures)
```

### 1. `ChowdeckError`
The base class for all SDK-specific errors. You can use this as a catch-all for any exception originating from the library.

```typescript
import { ChowdeckError } from '@chwdck/sdk';

try {
  await client.m.orders.get('merchant_ref', 'order_ref');
} catch (error) {
  if (error instanceof ChowdeckError) {
    console.error('An SDK error occurred:', error.message);
  }
}
```

---

### 2. `ChowdeckAPIError`
Thrown whenever the Chowdeck API returns a non-2xx HTTP status code (e.g. `400 Bad Request`, `401 Unauthorized`, `404 Not Found`, `422 Unprocessable Entity`, or `500 Internal Server Error`).

#### Properties
* `statusCode: number` — The HTTP status code returned by the server (e.g. `404`).
* `message: string` — The descriptive error message extracted from the server response.
* `responseData: any` — The raw, parsed JSON response returned by the API.
* `requestDetails: object` — Details of the outgoing HTTP request (`url`, `method`, `headers`, `body`).

```typescript
import { ChowdeckAPIError } from '@chwdck/sdk';

try {
  await client.m.orders.accept('invalid_merchant', 'invalid_order');
} catch (error) {
  if (error instanceof ChowdeckAPIError) {
    console.error(`HTTP Status: ${error.statusCode}`);
    console.error(`API Message: ${error.message}`);
    console.error(`Failed URL:   ${error.requestDetails.method} ${error.requestDetails.url}`);
    console.error(`Payload:      `, error.responseData);
  }
}
```

---

### 3. `ChowdeckConnectionError`
Thrown when the request fails before receiving an HTTP response from the server (e.g., DNS resolution failure, network disconnection, or socket timeout).

#### Properties
* `message: string` — Human-readable explanation of the connection failure.
* `originalError: Error` — The underlying native `fetch` / `TypeError` thrown by the JavaScript runtime.
* `requestDetails: object` — The request configuration that failed (`url`, `method`, `headers`, `body`).

```typescript
import { ChowdeckConnectionError } from '@chwdck/sdk';

try {
  await client.r.wallet.getBalance();
} catch (error) {
  if (error instanceof ChowdeckConnectionError) {
    console.error('Network failure:', error.message);
    console.error('Original runtime error:', error.originalError);
  }
}
```

## Ideal Error Handling Pattern

In real-world applications, combine these checks using standard TypeScript `instanceof` narrowing:

```typescript
import {
  chowdeck,
  ChowdeckAPIError,
  ChowdeckConnectionError,
  ChowdeckError,
} from '@chwdck/sdk';

const client = chowdeck({ apiKey: process.env.CHOWDECK_API_KEY! });

async function safeAcceptOrder(merchantRef: string, orderRef: string) {
  try {
    const response = await client.m.orders.accept(merchantRef, orderRef);
    console.log('Order accepted successfully:', response);
    return response;
  } catch (error) {
    if (error instanceof ChowdeckAPIError) {
      if (error.statusCode === 404) {
        console.warn(`Order ${orderRef} was not found for merchant ${merchantRef}.`);
      } else if (error.statusCode === 401) {
        console.error('Invalid API Key. Please check your Chowdeck credentials.');
      } else {
        console.error(`API Error [${error.statusCode}]:`, error.message);
      }
    } else if (error instanceof ChowdeckConnectionError) {
      console.error('Unable to reach Chowdeck API. Check internet connection or retry later.');
    } else if (error instanceof ChowdeckError) {
      console.error('General Chowdeck SDK error:', error.message);
    } else {
      console.error('Unexpected non-SDK error:', error);
    }
    throw error;
  }
}
```
