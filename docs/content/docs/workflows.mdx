## Overview

Rather than presenting isolated API calls in a vacuum, this chapter demonstrates how the Chowdeck TypeScript SDK mirrors actual production workflows.

The value of the SDK is not just that it provides access to over 50 REST endpoints—it is that it combines these endpoints into clean, predictable, and maintainable business flows: **Merchant Onboarding → Catalog Management → Order Processing → Webhook Verification → Courier Logistics**.

---

## SDK vs. Raw REST API

To see the difference immediately, consider what it takes to accept an incoming merchant order:

### Using the Raw REST API
```typescript
//  Raw REST API requires manual URL concatenation, auth headers, error parsing, and JSON serialization
const response = await fetch(
  `https://api.chowdeck.com/merchant/${merchantRef}/orders/${orderRef}/accept`,
  {
    method: 'POST',
    headers: {
      Authorization: `Bearer ${process.env.CHOWDECK_API_KEY}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({ notes: 'Preparing order in kitchen.' }),
  }
);

if (!response.ok) {
  const errPayload = await response.json().catch(() => ({}));
  throw new Error(`HTTP ${response.status}: ${errPayload.message || 'Unknown error'}`);
}

const data = await response.json();
```

### Using the Chowdeck SDK
```typescript
//  Clean, fluent, fully typed with automatic parameter validation and standardized error handling
const data = await client.m.orders.accept(merchantRef, orderRef, {
  body: { notes: 'Preparing order in kitchen.' },
});
```

## The Complete End-to-End Workflow

The following comprehensive example walks through a complete end-to-end merchant and logistics cycle.

```typescript
import {
  chowdeck,
  ChowdeckAPIError,
  koboToNaira,
  nairaToKobo,
  verifySignature,
} from '@chwdck/sdk';

const client = chowdeck({ apiKey: process.env.CHOWDECK_API_KEY! });
const webhookSecret = process.env.CHOWDECK_WEBHOOK_SECRET!;

async function runPlatformFlow() {
  try {
    console.log('=== Step 1: Verify Merchant Profile & Wallet ===');
    const merchantRef = 'mer_lagos_grill_01';
    
    const merchant = await client.m.get(merchantRef);
    console.log(`Merchant Name: ${merchant.data.name}, Status: ${merchant.data.is_open ? 'Open' : 'Closed'}`);

    const wallet = await client.m.wallet.getBalance(merchantRef);
    console.log(`Available Wallet Balance: ₦${koboToNaira(wallet.data.balance)}`);

    console.log('\n=== Step 2: Create a Promotional Discount ===');
    // Using currency helper: ₦500 off becomes 50000 Kobo
    const discount = await client.m.discounts.create(merchantRef, {
      title: 'Weekend Flash Sale',
      discount_type: 'flat',
      value: nairaToKobo(500),
      minimum_spend: nairaToKobo(3000),
      usage_limit: 100,
      start_date: new Date().toISOString(),
      end_date: new Date(Date.now() + 86400000 * 2).toISOString(),
    });
    console.log(` Created discount: ${discount.data.title}`);

    console.log('\n=== Step 3: Handle Incoming Order Webhook ===');
    const simulatedWebhookBody = JSON.stringify({
      event: 'order.created',
      data: {
        merchant_reference: merchantRef,
        order_reference: 'ord_987654321',
        total_amount: 850000, // 8,500 NGN in Kobo
      },
    });
    const simulatedSignature = 'simulated_hmac_sha256_signature';

    // Verify webhook authenticity securely using timing-safe buffer equality
    const isWebhookValid = verifySignature(
      simulatedWebhookBody,
      simulatedSignature,
      webhookSecret
    );

    console.log(`Webhook Signature Authenticated: ${isWebhookValid}`);

    console.log('\n=== Step 4: Accept and Process Order ===');
    const orderRef = 'ord_987654321';
    const acceptedOrder = await client.m.orders.accept(merchantRef, orderRef);
    console.log(` Order ${orderRef} accepted. Status: ${acceptedOrder.status}`);

    // Mark food as prepared and ready for pickup
    await client.m.orders.ready(merchantRef, orderRef);
    console.log(` Order ${orderRef} marked ready for pickup.`);

    console.log('\n=== Step 5: Dispatch Relay Courier ===');
    // 1. Fetch real-time delivery fee quote
    const quote = await client.r.deliveries.quote({
      pickup: {
        address: '14 Admiralty Way, Lekki Phase 1, Lagos',
        latitude: 6.4474,
        longitude: 3.4723,
        contact: { name: 'Lagos Grill Kitchen', phone: '+2348011112222' },
      },
      dropoff: {
        address: '25 Fola Osibo St, Lekki Phase 1, Lagos',
        latitude: 6.4512,
        longitude: 3.4689,
        contact: { name: 'Jane Doe', phone: '+2348033334444' },
      },
    });

    const feeId = quote.data.fee_id;
    console.log(` Quote received: ₦${koboToNaira(quote.data.amount)} (Fee ID: ${feeId})`);

    // 2. Book the dispatch
    const delivery = await client.r.deliveries.create({
      fee_id: feeId,
      description: `Delivery for Order #${orderRef}`,
      notes: 'Fragile meal package. Please handle with care.',
    });

    const deliveryRef = delivery.data.reference;
    console.log(` Courier booked successfully. Delivery Reference: ${deliveryRef}`);

    console.log('\n=== Step 6: Track Delivery Status ===');
    const tracking = await client.r.deliveries.get(deliveryRef);
    console.log(`Current Delivery Status: ${tracking.data.status}`);

    console.log('\n Entire merchant, order, and logistics flow completed seamlessly!');
  } catch (error) {
    if (error instanceof ChowdeckAPIError) {
      console.error(` API Error [${error.statusCode}]: ${error.message}`);
      console.error('Response body:', error.responseData);
    } else {
      console.error(' Unexpected failure:', error);
    }
  }
}

// Execute the workflow
await runPlatformFlow();
```
